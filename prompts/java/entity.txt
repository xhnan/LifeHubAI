## 要求

### 1. Base{class_name} 类（基类）
请生成包含所有字段的基类，包含以下内容：

1. **类注解**：
   - `@TableName("{table_name}")` - 指定数据库表名
   - `@Data` - Lombok 自动生成 getter/setter
   - `@Schema(description = "{table_comment}")` - SpringDoc API 文档注解

2. **字段注解**：
   - 主键字段：`@TableId(type = IdType.AUTO)` 或 `@TableId(type = IdType.ASSIGN_ID)`
   - 普通字段：当字段名与属性名不一致时使用 `@TableField("column_name")`
   - 逻辑删除字段：`@TableLogic`
   - 自动填充字段：`@TableField(fill = FieldFill.INSERT)` 或 `INSERT_UPDATE`
   - SpringDoc 注解：`@Schema(description = "字段说明")`

3. **注释规范**：
   - 类级别：使用 JavaDoc 注释说明表名和作者信息
   - 字段级别：使用 SpringDoc `@Schema` 注解替代 JavaDoc

4. **字段命名**：
   - 将数据库下划线命名转为驼峰：user_name → userName
   - 类型参考基础 Prompt 中的映射规则

5. **其他要求**：
   - 自增类型的主键使用 Long 类型

### 2. {class_name} 类（继承类）
生成一个空类，继承 Base{class_name}，用于后续扩展业务逻辑。
