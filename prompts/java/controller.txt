## 要求
请生成简洁的 RESTful Controller，包含以下内容：

1. **类定义**：
   - 添加 `@RestController` 注解
   - 添加 `@RequestMapping("/{module_name}/{table_path}")` 注解（注意：路径格式为 /模块名/表路径）
     - 例如：sys_user 表 → 路径为 `/sys/user`
     - 例如：sys_user_role 表 → 路径为 `/sys/userrole`
   - 添加 `@Tag(name = "{table_comment}", description = "{table_comment}管理")` 注解（SpringDoc）
   - 使用 `@Autowired` 注入 Service

2. **包声明**：
   - 包路径：`{package_path}.controller`

3. **依赖注入**：
   - 使用 `@Autowired` 注入 Service：`@Autowired private {class_name}Service {class_name_lower}Service;`

4. **RESTful API 端点**：
   - `POST /` - 新增
   - `DELETE /{{{id}}}` - 根据ID删除
   - `PUT /` - 更新
   - `GET /{{{id}}}` - 根据ID查询
   - `GET /` - 查询所有列表
   - `GET /page` - 分页查询

5. **接口规范**：
   - 类级别使用 `@Tag` 注解说明模块
   - 方法级别使用 `@Operation(summary = "接口说明")` 注解
   - 参数使用 `@Parameter(description = "参数说明")` 注解
   - 返回统一结果格式：`ResponseResult<T>`
   - 使用三元运算符简化成功/失败处理

6. **命名规范**：
   - Service 变量名使用小驼峰：`sysUserService`、`sysAppService`
   - 方法名简洁：add、delete、update、getById、list、page
